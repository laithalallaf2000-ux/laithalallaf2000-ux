### Maison Élan — Tennis Stories

A static, prerendered React site for a fictional tennis film and photography studio.

[**Live site**](https://xn--lan-9la.karinnasrallah.com) · [**Code**](https://github.com/laithalallaf2000-ux/MAISON-LAN)

The interesting part is not the layout — it is what happens at build time:

- **One real HTML file per route**, each carrying its own title, description, canonical URL,
  Open Graph tags and JSON-LD. Crawlers and link previews work with no server involved.
- **A single routing table** shared by the browser and the build script, so a page cannot
  ship with another page's metadata — the build fails loudly instead of shipping it quietly.
- **Motion that yields.** Every GSAP timeline, the Lenis smooth scroll and the cursor trail
  switch off under `prefers-reduced-motion`, and the content still reads correctly without them.
