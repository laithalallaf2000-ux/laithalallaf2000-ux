### Maison Élan — Tennis Stories

A tennis film studio's site: editorial typography, scroll-driven motion, and a build that
takes SEO seriously.

[**Live**](https://xn--lan-9la.karinnasrallah.com) · [**Code**](https://github.com/laithalallaf2000-ux/MAISON-LAN)

Designed and built end to end. The parts I care about:

- **Motion with a reason.** Parallax tied to scroll position, a staggered intro curtain, a
  cursor ribbon that eases toward the pointer — and every bit of it switches off under
  `prefers-reduced-motion`, with the page still reading correctly without it.
- **One real HTML file per route.** The build emits per-route titles, descriptions, canonical
  URLs, Open Graph tags and JSON-LD, so link previews and crawlers work with no server.
- **A build that refuses to ship quietly.** Page metadata comes from one shared table; if a
  tag goes missing the build fails instead of shipping the wrong one.
